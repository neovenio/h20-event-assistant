# Handoff: #31 Initial bundle budget

## What changed

- `src/app/app.routes.ts`: `/admin` now lazy-loads `Admin` via `loadComponent: () => import('./event-assistant/components/admin').then((m) => m.Admin)`, keeping `canActivate: [staffGuard]` and all 9 child section routes (`bookings` default + wildcard fallback).
- `src/app/app.ts` / `src/app/app.html`: removed eager `Admin` import from `App` and replaced `<app-admin>` inside `@case ('admin')` with `<router-outlet (activate)="attachAdmin($event)" (deactivate)="detachAdmin()" />` gated by `@if (admin())`, wiring `selectBooking`, `newBooking`, and `logout` outputs back to the shell.
- `src/app/event-assistant/components/admin.ts` / `admin.html`: kept optional `section = input<string>()` for standalone/test callers (`admin.spec.ts`) and added `activeSection` fallback derived from the `/admin/:section` URL segment when hosted by `<router-outlet />`.
- `src/app/app.html` / `src/app/app.ts`: wrapped `<app-event-builder #builderRef>`, `<app-booking-form>`, and `<app-booking-detail>` in `@defer (on immediate)` blocks inside their `@if` guards (using template reference query `viewChild<BuilderHandle>('builderRef')` so `EventBuilder` splits cleanly into a lazy chunk while opening immediately).
- `src/app/event-assistant/event-store.ts`: lazy-loaded `./data/initial-data` via dynamic `import()` inside `afterNextRender` (tracked with `PendingTasks`) only when entering local demo mode without a saved state, avoiding shipping demo fixtures in the initial/live bundle.
- `src/app/app.routes.spec.ts`: added tests covering staff `/admin` -> `/admin/bookings` lazy rendering, `/admin/logs` deep-linking, fragment preservation + demo staff mode, output forwarding (`selectBooking`, `newBooking`, `logout`), and non-staff `staffGuard` redirect to `/`.
