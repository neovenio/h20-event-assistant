# Handoff: #18 Match visual design to the official H20 website

## What changed

- `src/index.html`: Added `<link rel="preconnect">` hints for `https://fonts.googleapis.com` and `https://fonts.gstatic.com` (`crossorigin`) plus the Google Fonts `Barlow` (`400`, `500`, `600`, `700`, `800`, `400` italic, `display=swap`) stylesheet link, along with a comment showing where H20's Adobe Fonts kit (`use.typekit.net/<kit-id>.css`) can be enabled once domain-allowlisted.
- `src/app/event-assistant/brand.css`:
  - Added `--h20-font-sans: 'nudista-web', 'Barlow', Arial, Helvetica, sans-serif;`, `--h20-charcoal: #333333;`, and `--h20-deep-blue: #364b9b;` from `eventlocatie.h20.gg`'s Elementor `.elementor-kit-5` specification while preserving `#000000`, `#ffffff`, `#e1014b`, and `#5fc2d2`.
  - Applied `font-size-adjust: from-font` on `:root` and `font-size-adjust: cap-height from-font` on `h1, h2, h3` to stabilize fallback font swaps.
  - Replaced raw `px` heading declarations with WCAG 1.4.4 zoom-safe `rem` `clamp()` scales (`h1` up to `3.125rem` / `50px`, `h2` up to `2.5rem` / `40px`, `h3` up to `1.5rem`), unitless `line-height` (`1.5` body, `1.15`–`1.2` headings), `text-wrap: balance` on bare headings, `text-wrap: pretty` on paragraphs, and `min-block-size` instead of fixed `height` on `.topbar`.
  - Updated CTA and action buttons to official Elementor pill styling (`border-radius: 999px`), primary `#e1014b` hovering to H20 cyan `#5fc2d2` with `#000000` text (`10.13:1` WCAG AAA contrast), crisp `6px`–`8px` radii on sidebar nav / cards / inputs / calendar cells, and high-contrast `:focus-visible` outlines (`#364b9b` on light surfaces, `#5fc2d2` on dark surfaces).
- `src/app/event-assistant/components/modal.ts`: Matched modal dialog border radius (`8px`), light border tokens, and responsive `clamp()` header typography to `brand.css`.
- `scripts/check-requirements.cjs` & `scripts/tests/brand-styling.test.cjs`: Added automated verification `'Officieel lettertype / webfont-stack ingesteld'` checking `brand.css` (`nudista-web` + `Barlow`) and `src/index.html` (`fonts.googleapis.com`), removed `'Visuele gelijkheid met officiële website en exact lettertype'` from the unresolved list, and added regression tests in `scripts/tests/brand-styling.test.cjs`.
- `docs/adr/0006-brand-typography-and-styling.md`: Documented the `eventlocatie.h20.gg` inspection (`nudista-web` + `.elementor-kit-5`), the open-licensed `Barlow` + `'nudista-web'` stack decision, and the optional Adobe Fonts domain-allowlist drop-in step.

## How to verify

- `node scripts/check-requirements.cjs` (prints `PASS: Officieel lettertype / webfont-stack ingesteld` and `PASS` for all static checks; note `'n8n URL ingesteld'` remains `ONTBREEKT` while `public/h20-runtime.json` has an empty `n8nWebhookBaseUrl` prior to #7, and exits `0` when pointed at a configured runtime file via `H20_RUNTIME_PATH`)
- `npm run format:check`
- `npm run lint`
- `npm run test:ci`
- `npm run build`

## Notes and follow-ups

- Do not hotlink `https://use.typekit.net/jcy4hly.css` until H20 authorizes the deployment domain in Adobe Fonts; once allowlisted, adding the `<link>` in `src/index.html` activates `"nudista-web"` automatically because it is already first in `--h20-font-sans` (see ADR 0006).
