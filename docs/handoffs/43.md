# Handoff: #43 Generate `[PROD]` n8n workflows B, C and D

## What changed

- `backend/n8n/generate-workflows.cjs`: a small `ENVS` table (`dev` / `prod`) holds output dir, name prefix, webhook path and id prefix, allowed origins, `FRONTEND_ORIGIN` and the runtime config file. The generation body is wrapped in `generate(env)` and run for dev (A-D, as before) and prod (B, C, D only).
- Output: `backend/n8n/workflows/prod/{B-public-api-and-proposals,C-employee-api,D-email-notifications}.json`.
- Prod values: paths `h20-prod/public|admin`, webhookIds `h20-prod-public|admin`, origins `https://h20-event-assistant-prod.web.app,https://h20-event-assistant-prod.firebaseapp.com`, `FRONTEND_ORIGIN` `https://h20-event-assistant-prod.web.app`, names prefixed `[PROD] `, setup notes name the prod files and `h20_records_prod`.
- Dev reads `public/h20-runtime.json`, prod reads `config/runtime/prod.json`. Dev output is byte-identical to `origin/main`.
- Empty prod `firebase.apiKey`: the generator exits 1 with a clear message before writing anything.
- `backend/n8n/tests/domain.test.cjs`: structure test now skips directories and covers prod files; new tests for prod values, dev unchanged, and the empty-key failure.
- Docs: `backend/n8n/README.md` (new "Production imports" section) and `docs/handoffs/9.md` §3 now say to import `workflows/prod/*`; manual path/key/CORS/FRONTEND_ORIGIN edits removed.

## Decisions

- Test hook: env var `H20_PROD_RUNTIME_CONFIG` overrides the prod config path, so the failure test uses a temp file and never touches `config/runtime/prod.json`.
- Workflow A is not generated for prod (no environment-specific values).
- Validation happens at load, so a bad prod config blocks the dev write too (fail fast, nothing partially written).

## How to verify

```sh
node backend/n8n/generate-workflows.cjs && npx prettier --write backend/n8n
# diff of top-level backend/n8n/workflows/*.json against origin/main must be empty
node --test backend/n8n/tests/domain.test.cjs
npm run test:ci && npm run lint && npm run format:check && npm run build
```
