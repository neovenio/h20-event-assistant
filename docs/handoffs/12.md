# Handoff: #12 Real PDF download of the concept offer

## What changed

- `src/app/event-assistant/pdf-offer.ts`: zero-dependency, client-side PDF 1.4 offer module:
  - `buildOfferDocument(booking, context)`: pure mapper producing an `OfferDocument` with the H20 brand header (`H20 EVENT LOCATIE`, `CONCEPTOFFERTE`, reference, formatted `dd-MM-yyyy` date, status, live vs demo banner), event details, customer & billing details, itemized `OfferLineItem[]` (main room, additional rooms, activities, catering packages, upgrades/addons with explicit `'Op aanvraag'` flags when rates are unknown), VAT/subtotal/total breakdown, explicit list of `'Op aanvraag'` items, and the mandatory indicative-price disclaimer.
  - Privacy enforcement: `internalNotes`, `reviewNotes`, and staff `planning` are never included in `OfferDocument` or rendered PDF output. `explanation` is included only when truthy and `context.admin || !context.live || booking.requestStatus === 'approved'`.
  - `renderOfferPdf(doc)`: genuine A4 (`595.28 x 841.89 pt`) PDF 1.4 binary generator (`Uint8Array`) using Type1 `Helvetica` and `Helvetica-Bold` with `/WinAnsiEncoding` (CP1252 single-byte encoding for `€` = `0x80`, Dutch diacritics `ë`/`é`/`è`/`ï`/`ö`/`ü`, `·`, `–`, `—`, `²`, and `\(`, `\)`, `\\` literal escaping), H20 brand styling (`#000000` header bar, `#E1014B` magenta accent stripe, `#5FC2D2` cyan section accents), automatic line wrapping, multi-page table/content pagination with `Pagina X van Y` footers, exact 20-byte `xref` offsets, and `%%EOF`.
  - `downloadOfferPdf(doc)`: creates an `application/pdf` `Blob`, triggers `<a download="H20-Conceptofferte-${reference}.pdf">`, and revokes the object URL immediately.
- `src/app/event-assistant/components/booking-detail.ts` & `booking-detail.html`:
  - Added `downloadingPdf` and `async downloadPdf()` lazy-loading `await import('../pdf-offer')` so `pdf-offer` compiles into a separate lazy chunk without increasing the initial bundle.
  - Footer now offers both **Download PDF** (`class="primary"`) and **Afdrukken** (`(click)="print()"`), preserving browser printing in both demo and connected modes.
- Tests:
  - `src/app/event-assistant/pdf-offer.spec.ts`: unit tests for `buildOfferDocument`, line-item pricing vs `'Op aanvraag'`, VAT totals, privacy stripping, CP1252/WinAnsi byte encoding & PDF string escaping, `%PDF-1.4` / `xref` / stream `/Length` / `%%EOF` structural validity, multi-page overflow, and `downloadOfferPdf`.
  - `src/app/event-assistant/components/booking-detail.spec.ts`: component tests verifying both **Download PDF** and **Afdrukken** in demo mode and connected (`n8n`) mode, including pending vs approved live proposal explanation privacy.

## Decisions

- **Zero external dependencies / no third-party data transfer**: PDF bytes are assembled directly in browser memory (`Uint8Array`), keeping customer contact/billing data strictly client-side and avoiding heavy libraries (`jspdf`/`pdfmake`) in `package.json`.
- **Lazy chunk loading**: `BookingDetail.downloadPdf()` dynamically imports `../pdf-offer`, keeping the initial bundle under the 500 kB warning budget.
