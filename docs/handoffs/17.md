# Handoff: #17 In-app intake & tour appointments with verified availability

## What changed

- **Backend (`backend/n8n/code/domain.cjs`, `backend/n8n/generate-workflows.cjs`, regenerated workflows)**:
  - Exported `APPOINTMENT_SLOTS`, `hasAppointmentConflict`, `availableAppointmentSlots(rows, date)`, and `publicAppointment`.
  - Added public unauthenticated `appointment-slots` action (allowed in workflow B `Access` node and `N8nClient` without an `Authorization` header) returning `{ date, slots }` with zero PII.
  - Added authenticated `book-appointment` action (`AF-<8-HEX>` reference, `status: 'pending'`, idempotent on `requestId` per `ownerUid`, integrated with `#14`'s reserve-first `resolveClaim`/`settleClaim` slot-claim protocol on virtual resource `'__intake__'`).
  - Extended `my-requests` with `appointments` scoped to `ownerUid`, `adminAction` `snapshot` with `appointments`, and added `appointment-status` (`confirm` | `cancel`) with conflict/closure re-verification and audit logging.
- **Frontend (`src/app/event-assistant/`, `src/app/app.*`)**:
  - Added `Appointment`, `AppointmentSlot`, `AppointmentFormat`, `AppointmentStatus`, and `AppointmentInput` in `models.ts`, plus pure slot/conflict helpers in `event-utils.ts`.
  - Extended `EventStore` (`appointments`, `ownAppointmentIds`, `ownAppointments`, backwards-compatible `DemoState` `localStorage` persistence, `getAppointmentSlots`, `createAppointment`, `changeAppointmentStatus`, and `refreshAdmin`/`logout` hydration) and `App` (`my-requests` restore & sign-in).
  - Created accessible `AppointmentModal` (`components/appointment-modal.ts`) wrapped in `@if (appointmentOpen) { @defer { ... } }` in `app.html` so it adds 0 bytes to the initial bundle.
  - Added `"Plan rondleiding / intake"` CTAs on Dashboard, Kennisbank, and Mijn voorstellen; rendered `store.ownAppointments()` in Mijn voorstellen; and added staff appointment management (**Bevestigen** / **Annuleren**) under `Admin` `availability` (`Beschikbaarheid & Afspraken`).
- **Tests & Docs**:
  - Added `#17` backend tests in `backend/n8n/tests/domain.test.cjs` and frontend unit tests in `src/app/event-assistant/appointment.spec.ts` and `n8n-client.spec.ts`.
  - Added `docs/adr/0005-in-app-appointments.md`.

## How to verify

Run each check separately:

- `node backend/n8n/generate-workflows.cjs`
- `npx prettier --write backend/n8n`
- `node --test backend/n8n/tests/domain.test.cjs`
- `npm run lint`
- `npm run test:ci`
- `npm run build`
- `npm run format:check`
