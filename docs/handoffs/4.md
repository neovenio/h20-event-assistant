# Handoff: #4 per-environment runtime config

## What changed

- `config/runtime/dev.json` (dev Firebase config, same as `public/h20-runtime.json`) and `config/runtime/prod.json` (prod placeholders: empty `apiKey`/`appId`/`messagingSenderId`, prod project id).
- `scripts/write-runtime-config.cjs <dev|prod> [outDir]`: validates the env file (only `n8nWebhookBaseUrl` and public Firebase web config keys, all strings) and writes `h20-runtime.json` into the build output.
- `scripts/runtime-config.test.cjs`: guards against extra (secret) keys, checks dev/prod project ids, and that `public/h20-runtime.json` equals dev.json. Run via `npm run test:config`, which is now chained onto `npm run test:ci`.
- CI: `deploy-dev` and `deploy-prod` each get a "Write <env> runtime config" step before the Firebase deploy. Build job untouched; no secrets needed.
- README: new "Runtime config per environment" section including how to fill in prod values.

## Verify

`npm run build`, `lint`, `test:ci`, `format:check` and the n8n domain test all pass.
Manual: `node scripts/write-runtime-config.cjs prod /tmp/x` then inspect `/tmp/x/h20-runtime.json`.
