# Handoff: #46 Count n8n rate limits with insert-first rate hits

## What changed

- `backend/n8n/code/domain.cjs`
  - Removed `checkRateLimit` and the `rateLimitWrite` row. Added `buildRateHit(action, keys, nowMs, id)`, `decideRateHit(rows, action, ownRowId, nowMs)` and `decideHit(context, rows, ownHitRowId, nowMs)`.
  - `publicAction`: chat and the `claiming` retry return `route: 'hit'` with `hitRow`. A new event-request returns the claim context with `hitRow`. Cheap validation (empty chat message, `validateRequest`) runs before the hit is built, so invalid requests create no hit.
  - `settleClaim(context, rows, ownRowId, ownHitRowId, nowMs)` decides the slot and the hit from one re-read. Results carry `deleteRowIds` (array) instead of `deleteRowId`.
- `backend/n8n/generate-workflows.cjs` (B and C, dev and prod)
  - B: removed `Rate limit payload`, `Record rate limit`, `After rate limit`, `Rate limit recorded`. Added `Needs hit`, `Write hit`, `Insert hit`, `Re-read records after hit`, `Decide hit`, `Prune payload`, `Prune expired hits`. `Needs Gemini` (fed by `Settle claim` and `Decide hit`) feeds `Gemini`; `Prune payload` hangs off `Respond`, so pruning runs after the webhook is answered; PR #50's Gemini chain is unchanged, and `Gemini fallback` reads its body from `Needs Gemini`.
  - B and C: `Write claim` emits claim plus hit (when present), `Settle claim` matches insert results by `recordId` (falling back to item order only when the output has no `recordId` at all), new `Lost claim ids` Code node feeds `Delete lost claim` (filter `={{ $json.id }}`) one id per item.
  - B setup sticky note and prod note name the new Data Table nodes.
- `backend/n8n/README.md`, `docs/adr/0007-rate-limit-hits.md` (protocol, ignored legacy rows, rejected alternatives).
- Tests: `backend/n8n/tests/domain.test.cjs` (concurrency in any order, spoofed IP, expiry and prune cap, id fail-closed, raw-row counting, event-request lose/429/held/claiming, privacy and snapshot, structure of dev and prod B and C, Code-node behaviour through a vm stub).
- Regenerated: `backend/n8n/workflows/{,prod/}{B-public-api-and-proposals,C-employee-api}.json`. D and A are unchanged.
