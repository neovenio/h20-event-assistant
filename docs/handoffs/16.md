# Handoff: #16 Descope WhatsApp notifications

## Decision summary

Automated WhatsApp notifications are formally descoped for the initial release in favour of SMTP email delivery via Workflow D (#11), recorded in [`docs/adr/0003-descope-whatsapp-notifications.md`](../adr/0003-descope-whatsapp-notifications.md).

- Workflow D (`backend/n8n/workflows/D-email-notifications.json`) already covers receipt (`received`) and proposal approval (`approved`) notifications via SMTP email using the mandatory `customer.email` field.
- WhatsApp Business messaging requires Meta Business verification, paid provider credentials (WhatsApp Cloud API, Twilio, or Bird), pre-approved message templates, and explicit opt-in tracking, none of which are provisioned for this release.
- Customer phone numbers (`customer.phone`) remain available to H20 staff for manual follow-up.

## What changed

- Added `docs/adr/0003-descope-whatsapp-notifications.md`.
- Updated `scripts/check-requirements.cjs` to detect `docs/adr/0003-descope-whatsapp-notifications.md`, print `BUITEN SCOPE (ADR): WhatsApp-notificaties (docs/adr/0003-descope-whatsapp-notifications.md)`, and update the delivery requirement line to `Directe e-mailaflevering (workflow D; WhatsApp buiten scope per ADR 0003)`.
- Added unit tests in `scripts/tests/check-requirements.test.cjs`.
